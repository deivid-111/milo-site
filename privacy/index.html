Privacy policy

Last updated: October 23, 2026

Milo is a Discord bot that runs miles programs for airlines in the Roblox game PTFS. This policy explains what Milo stores, why, and how to delete it. Questions: the Milo support server.

What Milo stores

  • Discord IDs: your user ID, and the IDs of the servers, roles and channels Milo is set up with.
  • Your activity in each airline: miles balance, lifetime miles, flights you claimed or were added to, tier, achievements, reward claims, and a history of miles earned and spent.
  • Roblox account (only if you link one): your Roblox user ID and username, so Milo can check Premium purchases and subscriptions. If you link with Sign in with Roblox, Milo only asks Roblox for those two things and lets the sign-in go straight away.
  • Premium records: which server got Premium, when, from which plan, and which Roblox account bought it.
  • Custom Bot (only if you use it): your bot's application ID, name and token. The token is stored encrypted and is only used to run your bot.
  • Server settings: the settings, branding, tiers, achievements, routes, rewards, events and alliances each airline sets up, and who owns each server Milo is in.

Milo doesn't read or store your messages, and only sees what you send to it through its commands.

Milo Utilities (the support server bot)

Milo Utilities only works in the Milo support server. To moderate it, it reads messages sent there and stores:

  • Moderation cases: warns, timeouts, kicks, bans and notes, with who did them and why.
  • Levels: your XP and level in the support server.
  • Logs: edited and deleted messages, joins, leaves and role changes are posted in staff-only log channels in the support server.

It also gives server owners who use Milo the Customer, Premium and Custom Bot roles there, based on the data above.

Why

To run the features you or your airline use: give and show miles, tiers and achievements, run reward shops, check Premium purchases on Roblox, and run Custom Bots. In the support server, Milo Utilities uses its data to keep the server safe. Milo never uses your data for ads.

The website

milo-bot.xyz has no accounts, cookies, ads or tracking. It's hosted on GitHub Pages and goes through Cloudflare, which see your IP address and browser details to deliver the pages and block attacks, under their own privacy policies. The Roblox sign-in page (milo-bot.xyz/link) loads its font from Google Fonts. It shows your sign-in code only in your browser and doesn't send it anywhere.

Sharing

Milo doesn't sell your data. Some of it is visible in the server you use it in (for example leaderboards, profile cards and flight lists). Milo checks Roblox's own services to confirm purchases and links, and Discord delivers everything Milo sends. Data is only handed to anyone else if the law requires it.

Keeping it safe

Data is stored on a private device run by the bot owner and backed up every day. Only the bot owner can get to the database, and Custom Bot tokens are encrypted. No system is perfectly safe, so if something ever leaks that affects you, it will be announced in the Milo support server.

How long it's kept

Until you delete it, or until the airline's server removes Milo and asks for its data to be deleted. Daily backups are kept for 14 days. Premium purchase records are kept as long as needed for payment disputes.

Deleting your data

Run /privacy in any server with Milo:

  • Delete my data here removes your miles, flights, achievements, history and reward claims in that server.
  • Delete everywhere does that in every server, and removes your Roblox link.

Server admins can ask for a whole server's data to be deleted at the Milo support server.

Your rights

You can also ask in the Milo support server for a copy of your data, to have something corrected, or for Milo to stop using it. You'll get an answer within 30 days. Depending on where you live (for example the EU or the UK), you can also complain to your local data protection authority.

Children

Milo is for people old enough to use Discord under Discord's Terms of Service (13 in most countries). The monthly Premium and Custom Bot plans are bought in a Roblox game that only lets in players 16 and over. If you think a child under that age has data in Milo, tell us in the Milo support server and it will be deleted.

Changes

If this policy changes, the date at the top changes too. Big changes are announced in the Milo support server.
